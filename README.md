# jedli-site

Minimal Astro academic website for Jed Li.

## Run

```bash
npm install
npm run dev
```

Open the URL Astro prints (normally `http://localhost:4321`).

If you already created a blank Astro site with `npm create astro@latest`, you can simply copy the `src/` and `public/` folders from this package into it. You can also copy `astro.config.mjs`.

Routes included:
- `/`
- `/research/`
- `/publications/`
- `/notes/`
- `/cv/`
- `/blog/`

`astro.config.mjs` is preconfigured for `https://jedli.me`.
